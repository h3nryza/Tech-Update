Tech Update

Aggregated tech news dashboard — 13 products, 9 topics, 386+ sources

GitHub Pages Alpine.js Tailwind CSS Node.js

What It Does

  • Aggregates news from 386+ curated sources across cloud, DevOps, AI, and productivity
  • 22-tab dashboard: 13 products (AWS, Azure, Terraform, etc.) + 9 topics (SRE, DevOps, SecOps, etc.)
  • Colour-coded tags: #new, #update, #feature, #breaking-change, #security, #zero-day, #tutorial, #podcast, #article, #video, #social
  • Search by keywords or #tags, filter by date range
  • Export to CSV, JSON, or PDF
  • Dark/light mode with system preference detection
  • Fully responsive: table on desktop, cards on mobile
  • 365-day rolling archive with weekly snapshots

Quick Start

# Install collection dependencies
cd scripts && npm install

# Parse sources from markdown
node parse-sources.js

# Collect news from feeds
node collect.js

# Build search index
node build.js

# Open the dashboard
open ../index.html
