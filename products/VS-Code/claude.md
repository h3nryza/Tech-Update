- **Most authoritative**: VS Code Blog + Release Notes at code.visualstudio.com (monthly releases)
- **Only dedicated podcast**: VS Code Insiders Podcast (launched Dec 2025, biweekly)
- **Only dedicated newsletter**: VSCode.Email (weekly, ~2,173 subscribers)
- **Fastest news**: Visual Studio Magazine publishes multiple articles per week
- **Note**: VS Code switching to faster releases starting v1.111 (early 2026)
